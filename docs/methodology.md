## 二、五大核心指标与统计口径

### 1. 真实往返延时（Real RTT Ping）
- **排除虚假 Ping**：部分节点提供商在客户端返回的是本地虚拟网卡的本地 Ping（如 1ms~5ms），具有严重欺骗性。
- **评测标准**：我们通过向目标落地服务器（如香港、日本、美国 POP 点）发起多次完整的 TCP 3 次握手与 TLS 1.3 握手探测，统计往返真实耗时（Round-Trip Time），剔除离群值后取中位数。

### 2. 晚高峰吞吐与 4K 起播时延（Time to First Frame）
- **测试载体**：YouTube 官方移动客户端，播放标准 4K 60fps HDR 测试视频；
- **测量指标**：
  - **首帧渲染耗时**：从点击视频到第一帧画面流畅渲染的毫秒数；
  - **拖拽缓冲延迟**：随机拖拽进度条至任意未缓冲节点后的重新加载耗时；
  - **晚高峰持续吞吐量**：通过 YouTube 统计信息（Stats for Nerds）记录 Connection Speed 持续稳定性。

### 3. 移动基站漫游与断线自愈耗时（Roaming Recovery Time）
- **模拟弱网场景**：模拟用户进出电梯、地下车库以及高速移动中的基站频繁跳跃；
- **自愈计时**：从底层物理网卡重新获取到 IP 起，计算代理客户端（VpnService / NetworkExtension）静默重建加密隧道并恢复数据收发的全流程耗时（优选标准：< 0.5 秒）。

### 4. 移动芯片功耗与机身温升监测
- **监测方式**：在 26°C 恒温环境下，手机保持 50% 屏幕亮度与 120Hz 刷新率，运行指定客户端持续播放 1 小时 4K 视频；
- **记录指标**：
  - 电池百分比消耗量；
  - 硬件功率计记录的平均放电电流（mA）；
  - 红外热成像仪监测的机身主板区域最高温升值（°C）。

### 5. 流媒体与人工智能原生解锁核验
- 自动化脚本周期性调用 Netflix、Disney+、ChatGPT、Claude、TikTok 的身份认证与风控 API，检测出口 IP 是否为纯净原生商宽/家宽，标注是否触发 Cloudflare 验证码或被拒之门外。

## 三、数据更新与淘汰机制

- **每日拨测**：自动化监控探针每日 24 小时对收录的重点服务商进行可用率（SLA）轮询；
- **月度重估**：每月全量复核各品牌套餐价格、协议升级状态与测速大表；
- **黄牌下架机制**：若某服务商连续 72 小时出现大面积断流、工单无人响应或存在恶意倒卖隐私行为，实验室将立即予以风险警示并取消推荐。
